# 🌞 Sunnyside Agency Landing Page
This project is a fully responsive landing page for Sunnyside Agency, a fictional creative agency. The page is designed to showcase the agency's expertise in helping brands grow through compelling visuals and standout marketing strategies.

![Screenshot of the page](/images/screenshot-1.png)

![Screenshot of the page](/images/screenshot-2.png)

## ✨ Features
- Fully Responsive Design: Provides an optimal viewing experience across all devices, from large desktop screens to mobile phones.

- Modern and Creative UI: Visually showcases the agency's creative focus with a clean, image-forward layout.

- Interactive Elements: Includes a functional mobile navigation menu with JavaScript.

- Clean Code Structure: Uses BEM methodology for CSS class naming, making styles more maintainable and scalable.

## 🚀 Live Demo
Try the live version here: https://styn1s.github.io/Sunnyside-Agency/ 

## 🛠️ Technologies Used
- HTML5: For semantic and structured page content.

- CSS3: For custom styling, layout, and responsive design. Class names follow the BEM (Block, Element, Modifier) methodology.

- JavaScript: For interactive elements, such as the mobile navigation toggle.
